# Rust Photo Editor

[Compositor](https://github.com/robbietilton/Compositor)를 참고하는 Rust 데스크톱 이미지 편집기. Windows에서 개발 중이며, 전체 지원 목표는 [개발 체크리스트](DEVELOPMENT_CHECKLIST.md)에 유지한다. 아래 내용은 **현재 구현 상태**다. 전체 계획의 완료를 뜻하지 않는다.

## 실행

Windows 실행 파일: `target/release/photo_editor.exe`.

```powershell
cargo run --release
# 파일을 지정해서 열기
cargo run --release -- "D:\images\photo.png"
```

문서가 없을 때는 사진 열기와 새 문서 화면을 표시한다. 왼쪽 도구와 상단 옵션은 문서를 만들거나 연 뒤 표시한다. 이미지 형식 목록을 나열하던 시작 화면 안내 문구는 제거했다.

## 현재 사용할 수 있는 기능

- 문서 탭, 새 문서의 크기·투명 배경·RGB 8/16/32비트 설정, 수정 표시, 저장·폐기·취소 확인.
- 창 메뉴에서 레이어·속성·히스토리·색상·내비게이터·도구 표시와 패널 좌우 배치를 고른다. 패널 폭·표시·배치·도구 묶음의 마지막 선택과 사용자 단축키는 `%LOCALAPPDATA%/PhotoEditor/workspace.json`에 저장한다(`PHOTO_EDITOR_DATA_DIR`로 위치 변경). 기본 레이아웃 복원은 사용자 단축키를 유지한다. 내비게이터는 전체 이미지·현재 영역 표시, 클릭/드래그 이동·확대·맞춤을 제공한다. 6개 작업 패널은 제목 클릭으로 접고 다른 제목 위로 끌어 순서를 바꾼다. 제목의 ⋮ 메뉴에서 위/아래 이동·분리·고정·닫기를 제공한다. 분리한 패널은 앱 안에서 이동/크기를 바꾸며 순서·위치·크기·접기 상태도 실행 간 복원한다. 닫은 패널은 창 메뉴에서 다시 연다.
- 도구는 같은 계열의 10개 묶음으로 표시한다. 작은 펼침 버튼이나 우클릭에서 다른 도구를 고르며 창 메뉴에서 19개 전체 표시로 전환한다. 창 → 단축키 설정에서 38개 명령/도구의 키 변경·해제·기본값 복원을 제공하고 충돌과 캔버스/텍스트 편집용 예약 키를 검사한다. 입력란·한글 조합·모달 편집 중에는 전역 도구 단축키를 막는다. 아래 키 안내는 기본 설정 기준이다. Ctrl+F 또는 편집 → 명령 검색에서 전체 메뉴와 도구를 이름·분류·현재 단축키로 찾는다. ↑↓로 선택하고 Enter로 실행하며 Esc로 닫는다. 실행할 수 없는 명령은 사유를 표시한다.
- 아이콘 도구 19개: 이동, 사각 선택, 타원 선택, 자유 올가미, 마술봉, 자르기, 브러시, 지우개, 복제 도장, 복구, 블러, 그라디언트, 채우기, 도형, 펜·경로, 텍스트, 스포이드, 손, 확대.
- 브러시 크기·불투명도·경도, 획 보간·흔들림 보정·Shift 직선 연결, 선택 영역에 제한된 픽셀 편집. 도장은 Alt+클릭으로 샘플 위치를 지정하고 정렬 유지/해제와 활성/전체 합성 샘플을 고른다. 복구는 주변 픽셀을 사용하는 기본 도구다.
- 색상 창: 창 → 색상·팔레트 또는 도구 열의 색상 버튼. RGB/알파·6/8자리 16진수 입력, 최근 16개 색상, 최대 256개 팔레트 추가/제거, 전경·배경색과 팔레트의 실행 간 복원을 제공한다. X는 색상 교환, D는 검정 전경/흰 배경 기본값이며 입력 창에서는 도구 단축키를 실행하지 않는다.
- 스포이드: 한 점 또는 3×3/5×5/11×11/31×31/101×101 평균, 활성 레이어 원본/최신 전체 합성, 전경/배경 적용을 고른다. Alt+클릭은 반대 대상에 적용한다. 평균은 문서 픽셀 격자에서 투명도를 가중하고 문서 가장자리에서 범위를 자른다. 공간 필터·효과가 있으면 정확한 샘플을 위해 전체 합성을 계산하므로 대형 문서에서는 클릭이 오래 걸릴 수 있다.
- 선택 추가·빼기·반전, 자유/다각형 올가미(클릭으로 점 추가, Enter/더블클릭 완료, Esc 이전 선택 복원), 색상 허용 오차·인접 설정, 레이어 알파·마스크에서 선택 만들기, 선택 경계 확대·축소·페더.
- 이동 도구의 대상에서 레이어/선택 경계/선택 픽셀을 고른다. 선택 픽셀은 Alt로 복제하고 Shift로 축을 고정한다. 레이어 밖 이동은 작업 버퍼를 확장해 보존하며, 변형된 레이어에서는 원본 픽셀 격자에 맞춘다. 픽셀 이동은 기존 마스크의 위치를 유지한다. 자유 왜곡/전단 행렬이 있는 레이어는 선택 픽셀 이동 전에 명시적으로 래스터화하며, 레이어 전체 이동은 원본을 유지한 채 바로 사용할 수 있다. 잠긴 레이어·그룹·벡터·마스크 편집 대상에서는 픽셀 이동을 거부한다.
- 레이어 생성·삭제·복제·이름·순서·표시·잠금·불투명도, 중첩 그룹·그룹 마스크·통과/격리 합성·클리핑. 그룹 이동과 복제·삭제는 자식에도 적용한다. 레이어 이름을 더블 클릭하거나 속성의 이름 버튼·명령 검색을 사용하면 목록 안에서 편집한다. Enter로 적용, Esc로 취소하며 바깥 클릭으로도 확정한다. 빈 이름은 적용하지 않고 중복 이름을 허용한다. 한 번 실행 취소로 이전 이름을 복원한다.
- 레이어 썸네일·그룹 접기, Ctrl/Shift 다중 선택, 다중 이동·복제·삭제·그룹 묶기, 우클릭 메뉴, 그룹 안/밖 드래그와 Alt 복제. 문서 탭/레이어에 끌어 문서 간 이동하고 Alt로 복사한다. 양쪽 문서에서 각자의 이동 명령을 취소할 수 있다. 마스크·보정·효과·잠금 상태와 불투명도·블렌드 툴팁을 표시한다.
- Normal/Dissolve부터 Hue/Saturation/Color/Luminosity까지 27개 블렌드 모드. 디졸브 패턴은 문서 좌표와 레이어 ID를 사용해 미리보기와 저장 결과를 일정하게 유지한다.
- 원본을 유지하는 레이어 배율·회전·좌우/상하 뒤집기·위치의 수치 편집, 명시적인 래스터화.
- Ctrl+T 또는 레이어 메뉴/속성에서 캔버스 변형 시작. 단일 픽셀·텍스트·벡터, 그룹 또는 Ctrl/Shift로 선택한 여러 레이어를 공통 상자로 비파괴 변형한다. 8개 크기 핸들·회전 핸들·내부 이동·수치 크기/각도/위치·좌우/상하 뒤집기, Shift 비율·15° 회전·축 고정과 Alt 중심 기준 조절을 제공한다. ‘자유 왜곡’에서는 네 모서리를 따로 이동해 원근을 바꾸고 변 핸들로 양 끝을 이동해 전단한다. 모서리 교차·면적 소실·원본/효과 영역을 가로지르는 투영은 적용하지 않는다. 그룹 마스크와 자식 레이어를 함께 변형하며 원본·HDR·클리핑·편집 가능한 요소는 유지한다. 최근접/양선형/고품질 쌍입방 보간을 고르고, 투명도를 선곱해 투명 픽셀의 색이 경계에 섞이지 않게 한다. 신규 변형의 기본 보간은 양선형이고 기존 변형의 보간 설정은 다시 편집할 때 유지한다. 보기의 스냅을 켜면 실제 핸들·이동 경계가 가이드/격자/레이어/문서에 맞춰진다. Enter 적용/Esc 취소, 적용 한 번의 실행 취소와 프로젝트 저장·복원을 제공한다.
- 픽셀 마스크 생성·적용/비활성화·그리기·채우기·반전·페더·블러 브러시. 마스크 편집은 원본 색상 픽셀과 고정밀 자산을 바꾸지 않는다.
- 마스크 원본 보기: 창 메뉴 또는 마스크 속성에서 별도 창을 연다. 확대·맞춤·이동과 원본 좌표/값을 표시하고 그리는 중에도 갱신한다. 표시 버퍼는 최대 512×512이며 마스크 원본과 문서 이력은 바꾸지 않는다. 창 메뉴 또는 마스크 속성에서 마스크 오버레이의 색과 불투명도를 고른다. 캔버스 좌표의 숨김 영역에 색을 표시하며 회전·뒤집기·그룹 마스크와 편집 중 갱신을 반영한다. 표시 설정은 실행 간 복원한다. 마스크 연결/해제·독립 변형은 남은 목표다.
- 색상 균형은 그림자·중간톤·하이라이트의 9개 색 축과 광도 보존을 설정한다. 사진 블룸은 강도·반경·밝기 기준·부드러운 경계를 설정한다. “레이어 경계 밖까지 확산”을 켜면 투명 영역에도 빛을 퍼뜨리고 HDR 밝기를 유지한다. 끄면 기존 알파를 유지한다. 수동 렌즈 보정은 k1/k2 방사 왜곡·중심·확대·빨강/파랑 색수차와 보간을 설정한다. 영상이 접히는 설정은 적용하지 않는다. 세 기능 모두 원본과 프로젝트 설정을 보존하며 실행 취소한다. Lensfun XML 프로파일 보정·목록 병합/검색·촬영 정보 매칭·재실행 복원은 아래 구현 상태를 따른다. 실제 카메라/확장 별칭 매칭과 RAW 고급 섹션/프로파일은 남은 목표다.
- 레이어 → 색상 채우기/그라디언트 채우기/패턴 채우기에서 편집 가능한 채우기 레이어를 추가한다. 색상은 RGBA/8자리 색상 값, 그라디언트는 색상점/방향/보간을 설정한다. 패턴은 체크·줄무늬·점 또는 복사한 이미지/선택 영역을 원본 타일로 사용하며 배율·회전·위치·보간을 설정한다. 미리보기·적용/취소, 처음 선택한 영역의 마스크, 속성에서 재편집, 프로젝트/SVG 출력과 실행 취소를 제공한다. 패턴 타일은 8비트 RGBA PNG로 저장한다.
- 보정 창의 “톤별 대비”에서 전체 강도(0–100%), 그림자/중간톤/하이라이트 강도(−100–100%), 세부 반경(1–100px)을 조절한다. 양수는 주변 밝기와의 세부 차이를 높이고 음수는 부드럽게 한다. 알파·채널 색차·HDR/음수 RGB·원본을 유지하고 선택/페더 범위·조정 레이어·원본 적용·프로젝트/PSD/PSB 저장에 연결한다.
- 보정 창의 “레이어 경계 밖까지 확산”은 가우시안·모션 블러·블룸의 외곽을 표시하고 원본 적용·프로젝트·PSD/PSB에도 유지한다. 문서 경계·선택 범위·마스크를 적용하며 회전/배율/원근과 레이어 효과의 위치를 유지한다. 기존 문서와 기본값은 꺼져 있다. 외곽이 픽셀 예산이나 원근 투영 한계를 넘으면 적용을 막고 범위를 줄이도록 안내한다.
- 밝기·대비·노출·색조·채도·색온도·틴트, 블랙/화이트 레벨·감마, 자동 레벨, RGB 및 채널별 커브, 그라디언트 맵, 흑백·반전, 가우시안/모션 블러·선명화·그레인·색상 노이즈·비네트. 원본 기준 미리보기, 적용·취소와 설정 다시 편집을 제공한다. 선택이 있으면 “선택 영역에만 적용”으로 사각·타원·반전·페더 범위를 고정해 보정한다. 선택을 해제해도 저장한 범위는 유지되며 레이어/그룹 이동·변형에 따라간다. “적용”은 원본을 유지하고 “원본 픽셀에 적용”은 보정 결과를 픽셀에 기록해 설정을 초기화한다. 그룹 원본 적용은 내부 합성을 한 레이어로 변환한다. 다른 레이어와 블렌드되는 통과 그룹은 설정으로 유지하거나 통과를 끈 후 원본에 적용하며, 제한 사유를 표시한다. 범위/설정·적용/취소·프로젝트 복원과 한 번 실행 취소를 지원한다.
- 레이어 → 조정 레이어… 또는 명령 검색으로 현재 레이어 위에 별도 보정을 추가한다. 그룹을 선택하면 그룹 안에 추가한다. 아래 합성을 보정하며 통과 그룹은 그룹 아래 합성에도, 격리 그룹은 그룹 내부 합성에 적용한다. “아래 레이어에 클리핑”은 기준 레이어에만 적용한다. 표시·불투명도·블렌드·선택 범위, 마스크 그리기·반전·페더·독립 변형과 속성의 재편집을 제공한다. 원본을 복제하거나 덮어쓰지 않으며 생성·적용 한 번을 한 번의 실행 취소로 되돌린다. 조정만 선택한 픽셀 복사/래스터화는 사유를 알리고 레이어 구조 복사·합성 복사·병합을 제공한다. 부분 병합이 다른 레이어의 외관을 바꾸면 원본을 유지하고 적용 대상도 함께 선택하도록 안내한다.
- 레이어 효과 6개: 외곽선, 그림자, 색상 오버레이, 내부 그림자, 외부 글로우, 내부 글로우. 설정 편집·합성·프로젝트 복원을 제공한다.
- 가져온 SVG 레이어에서 펜의 “점 편집”으로 경로 목록 또는 캔버스 경로를 선택한다. 앵커/곡선 핸들 드래그, Alt 핸들 분리/모서리, Ctrl 곡선 분할, Delete 점 삭제와 Esc 취소를 제공한다. 여러 하위 경로·상대/이차/원호를 처리하고 그룹·뷰박스·레이어 변형을 반영한다. 선택한 경로의 d 속성만 변경해 CSS·그룹·그라디언트·참조·주석과 다른 요소를 보존한다. 프로젝트 저장과 한 번 실행 취소에 포함된다. 경계 밖 드래그는 뷰포트를 확장하며 기존 요소·마스크·보정 범위의 위치를 유지한다. 확장은 반복해도 래퍼를 누적하지 않으며 취소/실행 취소에 포함된다. 16/32비트 레이어의 작업 버퍼도 갱신하지만 SVG 자체 렌더링은 현재 8비트다. “요소 변형”에서는 기본 도형·경로·이미지·use 참조와 그룹을 캔버스에서 이동·8개 핸들 크기 조절·회전한다. 비율 유지와 Alt 중심 조절을 제공하며 원래 도형 속성/태그와 참조를 유지한다. 가져온 고급 CSS·동적 요소·외부 자산/글꼴·고정밀 벡터 렌더링은 남은 목표다.
- 사각형·둥근 사각형·타원·선, 다중 색상/알파 그라디언트, 다중 행 텍스트의 요소 설정 편집. 그라디언트는 색상점 2–256개의 위치·색·알파·추가·삭제와 기존 색상/선형 광량 보간·방향 반전을 설정한다. 반전은 정지점의 위치와 순서를 뒤집고 알파를 유지한다. 이전 프로젝트의 보간 필드가 없으면 기존 보간을 유지한다. 텍스트는 글꼴·크기·색·정렬·자간·행간·상자 크기와 자동 줄바꿈을 설정한다. 줄바꿈은 실제 글꼴의 글자 폭과 단어 경계를 사용하며 한국어 긴 단어도 상자 폭에 맞춘다. 이전 프로젝트의 두 색 그라디언트와 줄바꿈 없는 텍스트는 기존 설정을 유지한다.
- 펜·경로(P): 클릭으로 점을 찍고 드래그로 베지어 곡선을 만든다. 첫 점을 눌러 닫거나 Enter/완료로 열린 경로를 확정한다. ‘점 편집’에서 앵커·양쪽 핸들을 드래그하고 Ctrl+경로 클릭으로 점을 추가한다. Alt는 핸들 분리/모서리 전환, Delete/Backspace는 선택한 점 삭제다. 채우기·선·두께, 비파괴 변형, 프로젝트 저장·복원과 한 드래그 실행 취소를 제공한다. 경로를 키워도 회전·뒤집기된 고정점과 기존 마스크 위치를 유지한다. 도구 전환 시 두 점 이상인 초안을 열린 경로로 확정한다.
- 텍스트(T): 캔버스의 빈 곳을 눌러 문단을 만들고 기존 텍스트를 눌러 직접 편집한다. 한글 조합 입력·다중 행·문자 선택, 상단 막대 드래그 이동과 하단 모서리 크기 조절을 제공한다. 속성 창에서 문단 폭·높이·글꼴·크기·색상·정렬·자간·행간·줄바꿈을 바꾸고, 선택한 글자에는 별도 글꼴·크기·RGBA 색·굵게·기울임·밑줄을 적용한다. 설치된 글꼴 메뉴에서 한글/영문 이름을 검색·선택한다. 누락된 가족/스타일은 대체 표시를 안내하며 원래 이름은 프로젝트와 SVG에 유지한다. 문자 범위는 UTF-8 바이트가 아닌 Unicode 문자 기준이다. Ctrl+Enter로 적용하고 Esc로 취소하며, 조합 중에는 해당 단축키와 도구 전환을 막는다. 적용 또는 도구 전환을 한 번의 실행 취소로 기록한다. 회전·뒤집기·배율·클리핑·마스크와 글자별 스타일은 프로젝트에 유지한다. 회전된 문단도 편집 입력 상자는 화면 수평 방향으로 표시하며 적용 후 원래 변형을 반영한다. 입력 미리보기와 출력은 서로 다른 글꼴 배치 엔진을 사용하므로 글꼴에 따른 줄바꿈·자형 차이는 추가 화면 검증 대상이다.
- 가져온 SVG: 속성 → 요소 편집에서 내부 요소 목록과 현재 속성을 표시한다. 위치·크기·채우기·선·불투명도·transform·경로 d 등 속성, 선택 요소 XML 또는 전체 소스를 수정한다. 속성과 선택 요소 변경은 XML·렌더링 검사 후 반영하며, 선택하지 않은 그룹·defs·CSS·참조·마스크는 원본에 보존한다. 잘못된 전체 소스도 계속 수정할 수 있다. 프로젝트에 원본을 저장하고 요소 편집을 실행 취소한다. 가져온 SVG를 캔버스 펜의 앵커·핸들로 각각 편집하는 기능은 남은 목표다.
- 선택 픽셀 복사·잘라내기·붙여넣기, 합성 복사, 보이는/선택 레이어·그룹/아래 레이어 병합. 레이어·그룹 복사/붙여넣기도 제공한다. 복사는 앱 내부 클립보드로 문서 사이에서 사용하며 16비트/32비트 데이터를 유지한다.
- 캔버스/이미지 크기 변경, 투명 가장자리 자르기, 캔버스 좌우/상하 뒤집기. 화면 맞춤·100%·커서 중심 확대·화면 이동·픽셀 격자·히스토그램.
- 눈금자에서 끌어 가이드 생성, 이동 도구로 가이드 이동/캔버스 밖 삭제, 수치 편집, 격자 간격·세분화. 가이드/격자/레이어/문서 가장자리·중심 스냅과 이동 중 Shift 축 고정. 가이드·격자 설정은 프로젝트와 실행 취소에 포함하며 위치는 자르기·크기 변경·뒤집기에 맞춰 바뀐다.
- 자르기는 새 영역을 드래그하거나 기존 선택 영역에서 시작한다. 8개 경계 핸들·영역 내부 이동, X/Y/폭/높이 수치 입력, 자유/현재 문서/1:1/4:3/3:2/16:9 비율과 가로세로 교환, Shift 정사각형·Alt 중심 기준 조절·경계 및 이동 스냅을 제공한다. Enter/적용으로 문서 영역을 자르고 Esc/취소·다른 도구 전환으로 이전 선택을 복원한다. 미리보기 중 원본을 바꾸지 않고 적용 한 번을 실행 취소 한 항목으로 기록한다. 캔버스 밖 원본 픽셀과 변형·마스크를 유지한다.
- 실행 취소·재실행, 획과 수치 드래그를 하나의 편집으로 묶기. 파일 열기·저장·내보내기와 합성 미리보기는 백그라운드에서 처리한다. 오래된 미리보기는 최신 편집 결과를 덮어쓰지 않는다.
- 자동 저장(기본 30초, 15–600초 설정)·복구 목록. 원본 대신 별도 `.rphoto` 사본을 만들고 다음 실행 또는 파일 메뉴에서 복구한다. 실행 중인 다른 창의 사본은 파일 잠금으로 보호한다. 복구 문서는 저장 위치 없는 수정 문서로 열며 원본을 자동 덮어쓰지 않는다.
- 일부 복구 정보가 손상돼도 정상 사본을 나열하며 읽기 실패 내용을 보여 준다. 손상된 사본은 자동 삭제하지 않는다.

커브는 제어점 사이를 직선으로 보간한다. 그래프에서 더블 클릭으로 점을 추가하고 드래그로 이동하며 오른쪽 클릭으로 내부 점을 삭제한다. 자동 레벨은 불투명 픽셀의 밝기 분포에서 양 끝 0.5%를 제외한다. 그레인·노이즈는 같은 설정에서 같은 결과를 만든다.

APNG/GIF/WebP 애니메이션, 여러 페이지 TIFF와 여러 크기 ICO는 현재 한 장으로 열며 가져오기 안내를 표시한다. HEIC/AVIF도 대표 이미지 한 장을 읽는다. RAW 카메라/압축과 PCX의 추가 변형·`.comp`, 추가 인코더와 프레임·페이지 편집은 전체 계획에 그대로 남아 있다.

일반 이미지의 EXIF 방향은 적용한다. PNG·JPEG·TIFF·JPEG2000과 SVG 내부 이미지의 RGB/회색조 ICC는 작업 sRGB로 변환한다. 손상/채널 불일치·아직 처리하지 않는 범위 밖 HDR은 원래 픽셀을 유지하고 안내한다. 전체 형식/색 모드의 ICC와 일반 이미지의 ICC/EXIF/XMP 원본 보관·출력은 남은 목표다. 고정밀 픽셀 보존과 완전한 색 관리 지원은 별개의 상태다.

PNG 출력은 압축 수준 0–9와 자동/없음/왼쪽/위쪽/평균/Paeth 필터를 선택한다. 모든 조합에서 픽셀·알파·8/16비트를 유지하며 0은 압축 없음이다. JPEG·PPM·HDR의 투명 영역 배경색을 직접 고르거나 전경색·흰색·검정으로 설정한다. HDR는 현재 작업 버퍼의 RGB를 자동 색 변환 없이 RGBE로 기록한다.

## SVG 내보내기

파일 → 이미지 내보내기에서 SVG를 선택한다. 일반 도형·경로·그라디언트·글자별 스타일 텍스트를 벡터로 출력하고 위치·회전·배율·전단 행렬·불투명도·중첩 그룹과 변형된 그룹 마스크를 유지한다. 사진과 픽셀 마스크는 파일 안에 PNG로 포함하므로 외부 이미지 파일을 함께 전달할 필요가 없다. 앱에서 만든 선형 광량 보간 그라디언트도 PNG로 바꾸지 않고 SVG 표준 `color-interpolation="linearRGB"`와 원래 색상점·위치·알파로 출력한다. 같은 위치의 급격한 색 전환도 유지한다. 다시 열기 미리보기에서는 렌더러의 보간 차이를 보완하는 임시 색상점을 사용하며 저장할 원본을 바꾸지 않는다. 반투명 색상은 RGB 감마 변환과 알파 보간을 분리해 계산한다. 레이어마다 SVG ID를 구분해 여러 그라디언트의 참조가 충돌하지 않는다. 가져온 SVG는 CSS/참조를 정리해 출력하고 텍스트는 윤곽선으로 바꾼다. 가져온 선형 그라디언트는 현재 정규화 출력에서 분할 색상점으로 표현하므로 원래 SVG 구조를 그대로 출력하는 범위 확대는 남아 있다. 앱에서 만든 텍스트는 `<text>`로 유지하므로 다른 PC에서 같은 모양을 내려면 사용한 글꼴이 필요하다.

원근 왜곡·블렌드·클리핑·보정·효과 또는 고정밀 자산이 있는 문서는 현재 화면의 외관을 유지한 한 장의 8비트 PNG를 SVG 안에 포함하며 출력 전에 안내한다. 고정밀 원본과 편집 가능한 설정은 `.rphoto`에 보존한다. 가져온 SVG의 일반 요소·그룹·CSS·defs/참조·메타데이터·주석은 원래 구조로 출력한다. 여러 SVG의 ID/참조와 CSS 범위를 분리하고 :root 스타일을 같은 우선순위로 유지한다. 원본 XML은 프로젝트에 유지한다. 복잡한 효과/독립 마스크·고급 CSS/동적 요소/외부 자산/글꼴과 외부 프로그램 전수 검증은 남은 목표다.

## PSD와 PSB 저장

8/16/32비트 RGB 픽셀 레이어와 중첩 그룹, 이름·순서·위치·표시·잠금·불투명도·블렌드·클리핑·픽셀 마스크·가이드 위치를 읽고 저장한다. PSD/PSB의 길이 필드와 RLE 행 길이를 구분한다. 레이어와 병합 이미지에 RAW/RLE/ZIP/ZIP 예측 읽기를 제공하며 저장 화면에서 RAW/RLE/ZIP/ZIP 예측을 고른다. RLE·예측은 행 버퍼로, ZIP은 스트리밍으로 출력한다. 고정밀 레이어는 네이티브 Lr16/Lr32 전역 레코드에 저장하고 32비트 픽셀의 HDR/음수 RGB를 유지한다. 16비트 출력은 0–1 범위로 양자화한다.

Photoshop 이미지 리소스(ICC 포함)와 해석하지 않은 추가 레코드를 보존한다. 가이드 리소스는 편집한 위치로 갱신한다(1/32px 단위). 눈금자 표시·스냅·격자 세분화는 `.rphoto`에 저장한다. 편집 후 해석하지 않은 추가 레코드가 계속 유효한지는 보장하지 않으므로 저장 전 안내한다. 지원하지 않는 네이티브 텍스트·스마트 오브젝트·벡터 마스크·조정·효과 구조와 미연결 색 모드는 오류로 알린다. **고정밀 픽셀 마스크는 현재 8비트 편집 마스크로 변환한다.** 마스크 정밀도가 중요한 원본은 보관해야 하며 고정밀 마스크 보존은 남은 구현이다.

앱에서 만든 텍스트·벡터·보정·효과·변형은 PSD/PSB 내보내기에서 픽셀로 변환한다. 보정·효과가 적용된 그룹은 하나의 픽셀 레이어로 변환하며 문서의 16/32비트 정밀도를 유지한다. 별도 조정 레이어가 있거나 선택 범위 보정이 배경과 블렌드되는 통과 그룹에 있으면 외관을 유지하도록 전체 합성을 하나의 픽셀 레이어로 출력한다. 변환 내용은 저장 화면에서 안내한다. 편집 가능한 설정과 원본은 `.rphoto`로 보관한다.

소형 PSD와 가로 30,001px PSB, 중첩 그룹·마스크·클리핑·한글 이름·추가 레코드·가이드 왕복 테스트가 있다. 별도 Python 인코더의 16/32비트 ZIP 예측 파일을 읽고 별도 검사기로 생성 파일의 네이티브 레코드·픽셀·병합 이미지도 확인했다. 8비트 PSD 병합 이미지는 Pillow에서 확인했다. **Photoshop에서 양방향으로 다시 열어 보는 호환성 검증은 아직 수행하지 않았다.** 네이티브 텍스트·스마트 오브젝트·고정밀 마스크·CMYK/Lab까지 보존하는 목표는 체크리스트에 유지한다.

## 프로젝트와 처리 방식

`.rphoto`는 확장XMP 원문 자산이 있으면 버전15, IPTC/Photoshop 원문 자산이 있으면 버전14, EXIF/XMP 원문은 버전13, 원본ICC만 있으면 버전12, 4채널 센서 정보/네 번째 배율이 있으면 버전11, 색온도·틴트 RAW 설정이 있으면 버전10, 기본 RAW는 버전9, 일반 문서는 버전8로 저장한다. RAW 원본/현상 설정/센서 정보를 `layers/{id}-source.raw`와 설명 파일에 보존하고 버전1–15도 읽는다. 문서 고유 ID와 ZIP 안에 `manifest.json`, 8/16비트 PNG 또는 32비트 OpenEXR 원본, PNG 마스크, 조정 레이어 유형·요소·변형·보정·효과·그룹·가이드/격자 설정과 Photoshop 메타데이터를 저장한다. SVG/패턴 원본은 별도 `layers/{id}-source.svg` 자산에 저장해 큰 소스가 설명 파일 크기를 넘지 않게 한다. 버전 1–7도 읽고 가이드 설정이 없으면 기본값을 사용한다. 이름·저장 위치 변경·실행 취소에도 문서 ID를 유지하며 이전 파일은 새 ID를 부여한 뒤 v8로 저장할 수 있다. 보정의 선택 범위는 위치/반전/변형과 별도 `layers/{id}-adjustment-selection.png` 자산으로 저장하고 누락·크기 불일치·잘못된 변형은 거부한다. 복구 정보와 사본의 ID가 다르면 복원을 거부하며 기존 사본을 보존한다. 저장은 문서 스냅샷을 임시 파일에 기록하고 교체한다. 실패하면 이전 파일을 유지하며 이미지 내보내기는 프로젝트의 수정 표시를 지우지 않는다.

색상 설정은 Windows의 `%LOCALAPPDATA%/PhotoEditor/colors.json`에 저장한다. `PHOTO_EDITOR_DATA_DIR`을 지정하면 그 폴더의 `colors.json`을 사용한다. 색상 드래그가 끝나면 최근 색상과 설정을 원자적으로 저장하며 손상·지원하지 않는 설정 파일은 덮어쓰지 않는다. 최근 색상·팔레트는 앱 설정이며 문서 실행 취소나 프로젝트에는 포함하지 않는다.

열린 프로젝트·PSD·PSB는 2초 간격의 백그라운드 작업에서 파일 수정 시각과 크기를 확인한다. 외부 변경/삭제를 발견하면 현재 문서와 이력을 유지하고 새 버전을 별도 탭으로 열기·계속 편집·다른 이름 저장을 제공한다. 편집 중인 모달/획을 마친 뒤 알리며 같은 변경을 반복해서 알리지 않는다. 저장은 파일을 준비한 뒤 교체 직전에 변경 여부를 다시 확인하고, 충돌이 있으면 사용자 선택 전까지 외부 파일을 보존한다. 확인 실패는 상태 표시의 툴팁으로 알린다. 수정 시각/크기를 유지하는 변경 검출과 다른 프로그램과의 동시 저장 잠금은 추가 목표다.

자동 저장 위치는 Windows의 `%LOCALAPPDATA%/PhotoEditor/recovery`다. `PHOTO_EDITOR_DATA_DIR`을 지정하면 그 폴더 아래 `recovery`를 사용한다. 정상 저장/폐기/닫기 후에는 해당 문서의 사본을 정리하고 저장 중 바뀐 문서는 다음 주기에 다시 저장한다. 사본에는 원본 이미지와 프로젝트 내용이 포함된다. 실제 프로세스 강제 종료·전원 중단 전수 검증은 별도이며 테스트는 창 잠금과 중단된 세션 복원·저장/종료 경쟁을 검증한다.

좌표는 문서 픽셀과 화면 포인트를 구분하고 DPI 배율을 반영한다. 고정밀 편집은 RGBA `f32` 버퍼를 사용한다. RGB는 가져온 값의 공간에서 연산하며 문서 전체의 선형 합성/ICC 변환은 적용하지 않는다. 그라디언트에서 선택하는 선형 광량 보간은 sRGB 색상점 사이의 보간에만 적용한다. 알파는 비연관 값으로 보관하고 블러·합성에 필요한 부분에서 선곱한다. 화면 표시만 8비트로 제한한다. 16비트 출력은 0..1 범위, OpenEXR은 HDR 값을 유지한다.

브러시·지우개·리터칭 드래그는 변경 영역만 CPU에서 합성하고 화면 텍스처를 부분 갱신한다. 그룹·클리핑·마스크·16/32비트·블렌드 모드와 색 보정에도 적용한다. 전체 미리보기가 처리 중이면 이후 입력 영역을 모아 완료된 결과에 덧반영한다. 그림자·글로우·공간 필터·그룹 보정은 전체 합성을 별도 작업에서 수행하며, 연속 입력 때문에 완료된 결과를 버리지 않고 다음 결과로 이어간다. 다른 편집으로 무효화된 결과는 계속 거부한다. 전체 표시용 픽셀 변환과 히스토그램 계산은 별도 작업에서 수행하고, 그리기 중 히스토그램은 변경 픽셀만 갱신한다. 레이어 썸네일은 최대 28×28개 픽셀을 샘플링한다.

2026-10-06 같은 Windows PC에서 개발용 빌드의 32px 브러시로 8×4px 구간을 20번 그렸다. 4K 한 레이어의 그리기·부분 합성·텍스처 갱신 준비 중앙값은 약 1.01ms, 첫 입력은 약 5.79ms였다. 무효화된 썸네일을 포함한 속성 패널 처리 시간은 기존 약 561ms에서 약 1.29ms로 줄었다. 측정값은 화면 표시 전 CPU 처리와 업로드 준비 시간이며 GPU 업로드·실제 표시 지연은 포함하지 않는다. 연속 입력 16회는 매번 최신 픽셀을 반영하는 자동 테스트로 검증한다. 전체 합성 비용은 여전히 남아 있으며 그림자·블러가 있는 대형 문서의 동일한 반응 속도를 보장하는 수치는 아니다. 상세 측정은 `qa-output/brush-diagnosis/debug.json`과 `debug-after.json`에 기록한다.

현재 작업 예산은 문서·레이어 픽셀 합계 1억, 프로젝트 레이어 10,000개, 그룹 깊이 64다. 실행 취소는 최대 100항목/고유 픽셀 버퍼 256MiB를 기준으로 정리하되 마지막 한 항목은 보존한다. 마스크와 합성 임시 버퍼까지 포함하는 엄격한 전체 메모리 상한은 아직 없다. CPU 합성과 최근접/양선형/쌍입방 변형 샘플링을 사용하므로 GPU·타일·대형 문서 성능 개선이 필요하다. 이 예산은 최종 지원 범위를 축소하는 목표가 아니다.

## 남은 구현

이미지 편집 기능의 지원 목표를 유지하며 Windows용 실행 파일로 제공한다. WebP 출력에서 무손실/손실을 선택한다. 기본은 무손실이며 손실 모드에서는 품질 0–100과 압축 노력 0–6을 설정한다. 손실 압축에서도 알파는 보존하며 가로/세로 16383px 이하를 처리한다. WebP 출력은 현재 8비트 한 장이고 애니메이션·메타데이터/ICC·출력 미리보기 목표는 유지한다. libwebp 연결은 [webp 인코더 API](https://docs.rs/webp/0.3.1/webp/struct.Encoder.html)를 사용하며 배포 의존성 고지는 별도 목표다.

TIFF 출력은 자동(기존 8/16비트) 또는 8·16·32비트를 선택하고 없음/LZW/Deflate 3수준/PackBits로 저장한다. LZW/Deflate의 정수 수평 예측 또는32비트 부동소수점 예측, BigTIFF, 해상도 1–9600ppi를 설정한다. 무압축/PackBits에서는 예측을 사용하지 않는다. 32비트는 HDR·음수 RGB를 보존하고 알파는 비연관 값으로 기록한다. 8/16비트에서는 HDR 범위를 변환한다. 다중 페이지·ICC/전체 메타데이터는 별도 남은 목표다.

AVIF 출력은 색상 품질/투명도 품질 1–100, 속도 1–10, 8·10비트, YCbCr BT.601/BT.709 또는 RGB, 작업 스레드(0=자동)를 선택한다. 10비트는 고정밀 합성 원본에서 직접 변환한다. 출력은 현재 SDR이며 HDR/음수 RGB를 범위 안으로 변환하고 12비트·ICC/HDR 전달 곡선·메타데이터·다중 프레임 목표는 유지한다. 품질 100을 비트 단위 무손실로 보장하지 않는다.

JPEG는 기본 4:4:4와 품질 90을 유지하고, 자동/8종 색차 샘플링·색차 평균 샘플·프로그레시브 2–64스캔·압축 최적화·해상도·재시작 간격을 설정한다. 실제 파일에서는 성분별 스캔이므로 전체 SOS 수가 설정값보다 많다. 최대 192스캔 출력도 다시 열 수 있으며 EXIF 회전과 회색조/CMYK 입력을 유지한다. 저장·읽기 라이브러리의 실제 오류를 [로컬 수정](vendor/README.md)으로 보완했다. JPEG 정밀도는 8비트 RGB이며 ICC/메타데이터 전체 보존 목표는 유지한다.

GIF 한 장 출력에서 2–256색, 디더링, 완전 투명 영역 유지와 경계1–255, 인터레이스를 설정한다. 기본 경계는128이며 이보다 낮은 알파는 투명하게 저장하고 나머지 반투명 색은 배경색과 합성한다. 투명 영역 유지를 끄면 모든 픽셀을 배경색과 합성한다. 투명색도 선택 색상 수에 포함하고, 색이 적으면 정확한 팔레트를 유지한다. 그라디언트의 색 띠를 줄이려면 디더링을 사용한다. 애니메이션 편집/시간 보존과 메타데이터 목표는 계속 남아 있다.

이미지 내보내기 화면은16형식의 실제 전체 해상도 출력과 다시 읽기를 백그라운드에서 수행해 원본/저장 결과·파일 크기를 보여준다. 전체 보기의 위치를 클릭하면160px 부분을 물리적 화면 픽셀100%로 비교한다. 설정을 빠르게 바꾸면250ms 뒤 최신 설정을 처리하고 오래된 결과를 표시하지 않는다. 실시간 미리보기를 끌 수 있으며 옵션/미리보기는 각각 스크롤하고 저장/취소 버튼을 유지한다. 표시 버퍼는512px 이내이고 원본 정밀도는 변경하지 않는다. 화면 비교는 현재8비트 SDR이며 ICC/HDR 화면 목표는 남아 있다.

보기 → 화면 보간에서 최근접·부드럽게·고품질 축소를 선택한다. 기존 기본값인 부드럽게를 유지하고 선택을 작업 화면 설정에 복원한다. 고품질 축소는 배율별 텍스처 레벨을 생성/보간하며 브러시의 부분 갱신 뒤에도 선택을 유지한다. 레이어 변형의 보간과 독립적이며 원본/저장/실행 취소/배율에 영향을 주지 않는다. 명령 검색에서도3옵션을 실행한다. 실제 GPU에서의 선명도·대형 문서 성능/메모리 비교는 별도 남은 검증이다.

JPEG XL 읽기는 색/알파의 실제 정밀도와 범위 밖 값을 살펴8/16비트 또는32비트 작업 버퍼로 유지한다. 음수/HDR·부동소수점 회색조·미리 곱한 알파를 처리하고 JPEG XL 방향은 한 번만 적용한다. 대표 이미지 한 장이며 추가 채널/레이어·애니메이션 편집과 전체 ICC/CMYK는 남은 목표다. [libjxl 기준 예제](https://github.com/libjxl/conformance)의6종을 독립 float 픽셀과 비교했다. VarDCT의 RGB는 [디코더의 채널별 검사 기준](https://github.com/tirr-c/jxl-oxide/blob/f4dce3f/crates/jxl-oxide-tests/tests/conformance/mod.rs)을 사용하며 코퍼스의 더 엄격한 공통 알파 오차 기준/전체 ISO 적합성 통과를 주장하지 않는다.

회색조 PSD/PSB는8/16/32비트·α·그룹/클리핑/마스크를 읽어 같은 정밀도의 중성 RGB 작업 버퍼에 유지한다. 원본 리소스와 값은 .rphoto에 보존한다. Photoshop 출력에서 RGB/회색조를 선택하며 회색조 ICC는 회색조 출력과 프로젝트에 보존하고 RGB 출력에는 포함하지 않고 안내한다. 합성72종의 전체 값/정밀도/프로젝트를 독립 검사했다. ICC 색 변환·추가 알파/별색·다른 색 모드는 남은 목표다.

RGB PSD/PSB는 외부 파일의 레이어/그룹 순서와 폴더 블렌드 설정을 읽고 저장한다. 이전 개발 버전이 쓴 그룹 파일은 순서를 감지하며, 그룹 없는 이전 파일은 파일 → 이전 개발 PSD/PSB 열기…에서 연다. 원본 저장 위치 없는 문서로 열고 새 출력은 외부 순서를 따른다. 독립 구조·픽셀·저장 평면 검사를 완료했으며 투명 RGB 합성은 흰 배경 표현으로 저장/복원하며 원본 레이어 비트와 독립 표시 값을 확인했다. 실제 Photoshop 외관 검증은 남아 있다.

투명 RGB PSD/PSB의 합성 미리보기는 흰 배경 값으로 저장하고 평면 입력에서는 알파를 복원한다. 실제 레이어의 원래 RGB/α 비트는 유지한다. 낮은 알파의 합성 양자화 오차는 원본 정밀도와 구분하며 합성만 있는 α0의 숨은 색은 복구하지 못한다. 이전 straight 합성 파일은 이전 개발 파일 열기에서 읽는다.

PSD/PSB 내보내기에서 회색조를 선택하면 중성 원본의 8/16/32비트 레이어·그룹·마스크와 GRAY ICC를 유지한다. 컬러 원본은 기본 전체 합성을 한 회색조 레이어로 변환하며, “컬러 레이어 구조 유지”를 켜면 각 레이어를 변환한다. 레이어별 변환은 블렌드의 외관이 전체 합성 변환과 다를 수 있다. 현재 RGB 수치의 휘도를 사용하며 ICC/선형 색 변환은 적용하지 않는다. 원본 편집 구조는 .rphoto에 유지하고 RGB 출력도 계속 선택할 수 있다.

RAW는 파일 열기/레이어 가져오기로 센서 데이터를 현상한다. 레이어 → RAW 현상… 또는 속성의 같은 버튼에서 촬영값/중립/사용자 화이트 밸런스와 노출을 바꾼다. 선형 노출 후 sRGB 작업 값의32비트 결과를 유지하고 HDR/음수는 표시용 미리보기와 구분한다. 최신 설정의 결과만 적용하며 취소는 원본을 유지한다. 적용하면 직접 그린 픽셀을 RAW 현상 결과로 교체하고 마스크·위치·변형·레이어 보정을 유지하며 한 번 실행 취소한다. RAW 원본 바이트/현상 설정은 .rphoto에 유지하고 PSD/PSB/일반 출력은 현재 픽셀을 저장한다. RAW 디코더의 카메라/압축 범위와 전체 DNG 프로파일/3광원·DNG 룩/ICC·자동 렌즈/고급 RAW 섹션 목표는 별도다. [형식/예제](tests/fixtures/raw/README.md), [디코더 고지](licenses/rawler/README.md).

색 보정의 색상 믹서는 빨강·주황·노랑·초록·청록·파랑·보라·마젠타의 색조/채도/밝기를 각각 조절한다. 이웃 색상을 부드럽게 보간하며 개별·전체 초기화를 제공한다. 일반 레이어와 RAW 현상 결과, 조정 레이어 및 선택 영역에 적용하며 원본과 RAW 자산을 유지한다. 현재 작업 RGB 수치의 휘도를 사용하고 ICC 또는 Adobe 외관 일치를 주장하지 않는다.

컬러 그레이딩은 그림자·중간톤·밝은 영역·전체 톤의 색상환(방향=색조, 거리=강도), 밝기와 톤 혼합/균형을 제공한다. 톤별 또는 전체 초기화와 기존 적용/취소/실행 취소를 사용한다. 색상환은 현재 SDR 표시이며 작업 RGB 기반 수식과 ICC·참고 앱 외관 검증을 구분한다.

노이즈 감소는 밝기/색상 잡음의 강도, 반경1–8px와 허용 차이를 조절한다. 낮은 허용 차이는 경계를 더 보존하고 높은 값은 세부까지 부드럽게 할 수 있다. 투명 픽셀의 숨은 색을 제외하고 알파·RAW 원본을 유지한다. 현재 현상 후 작업 RGB의 가로/세로 경계 보존 필터이며 센서 AI 현상이나 실제 카메라 화질 검증을 주장하지 않는다.

세부 선명화는 강도·반경0.3–8px·임계값과 경계 제한을 제공한다. 밝기 차이를 같은 양으로 RGB에 더해 채널 차이를 유지하고, 임계값으로 작은 잡음의 강화를 줄이며 경계 제한으로 평탄한 영역을 보호한다. 노이즈 감소 뒤 색 보정 전에 처리하고 알파/RAW 원본은 유지한다. 기존 선명화 설정도 별도로 읽고 적용한다. 실제 카메라 화질/외관과 대형 문서 성능은 추가 검증 대상이다.

RAW 현상 화면에서 현재 레이어 원본과 현상 결과를 나란히 보고 전체 이미지의 위치를 클릭해 같은 위치를100%로 비교한다. 부분은 최대160×160px이며 화면 배율을 반영해1이미지 픽셀을1물리 화면 픽셀로 표시한다. 전체 표시는512×256이내/알파 가중 면적 축소로 백그라운드에서 준비하고 설정 변경 시 이전 결과를 숨긴다. 저장된 현상 설정으로 돌아가면 원본 표시를 복원한다. 비교는 레이어 보정/마스크/변형 전 RAW 픽셀이며8비트 SDR 표시, 원본32비트 정밀도는 유지한다.

RAW 현상 화면은 파일에 있는 렌즈 제조사/모델·초점거리·조리개·셔터속도·ISO를 표시하고 .rphoto9에 원래 분수와 렌즈 규격을 보관한다. 정보가 없는 파일에 값을 추정해서 넣지 않는다. 잘못된 분수/너무 긴 이름 또는 촬영 정보 해석 오류는 해당 정보를 제외하고 센서 픽셀과 RAW 원본을 유지한다. 전체 EXIF의 다른 형식 출력과 실제 카메라별 렌즈 프로파일 보정은 남은 목표다.

사진 보정의 렌즈 프로파일에서 Lensfun XML을 불러오고 교정값을 직접 선택하거나 RAW 촬영 정보로 정확히 일치하는 값을 찾는다. poly3/poly5/PTLens/ACM 왜곡을 지원하며 카메라 크롭 배율을 확인한 뒤 적용한다. 선택한 렌즈의 XML/원본 RAW/정밀도를 프로젝트에 보존한다. 측정값/범위 안 초점거리 보간으로 왜곡·색수차를 보정하며 주변부 밝기는 측정값/초점거리·조리개·거리 보간을 사용한다. 데이터베이스 확장·실제 카메라 화질 검증을 다음 항목으로 유지한다.

렌즈 프로파일에 색수차 교정값이 있으면 별도 체크박스로 켠다. linear/poly3/ACM 모델로 빨강·파랑 위치를 보정하고 녹색·알파의 기준 위치를 유지한다. 색수차만 있는 프로파일도 고를 수 있다. 교정값 선택 시 색수차는 기본으로 꺼져 있으며 촬영 초점거리/크롭 배율과 가장자리 색을 확인한 뒤 사용한다.

렌즈 프로파일의 주변부 밝기는 PA/ACM 교정값을 선택해 별도로 켠다. RAW 조리개와 같은 값이 하나일 때 자동으로 선택하고, 같은 조리개에 여러 교정 거리가 있으면 직접 고른다. 현재 작업 RGB를 확장 sRGB로 보고 선형 밝기에서 보정한 뒤 왜곡/색수차를 적용한다. 투명 픽셀·알파·원본과 레이어 밖 필터 확산은 유지하며 ICC/실제 카메라 화질 검증은 남는다.

렌즈 프로파일의 보정 초점거리를 입력/드래그한 뒤 계산 버튼을 누르면 호환 측정값 사이의 왜곡·색수차를 보간한다. 범위 밖/중복/잘못된 계산은 기존 설정을 유지한다. 교정 그룹이 여러 개이면 자동 매칭을 보류하며 직접 선택할 수 있다. 원래 XML을 프로젝트에 보관해 별도 데이터베이스 없이 다시 계산한다. 보간 숫자는 저장/읽기에서64비트 정밀도를 유지한다.

주변부 밝기의 조리개와 교정 거리를 입력/드래그한 뒤 계산 버튼을 누르면 보정 초점거리와 함께3축으로 보간한다. 계산만으로 밝기 스위치를 켜지는 않으며 너무 먼/잘못된 값은 기존 설정을 유지한다. 현재 켜진 왜곡·색수차를 새 초점거리에서 계산할 수 없으면 전체 변경을 거부한다. 계산 입력/결과와 원래 XML을 프로젝트에 저장한다.

렌즈 프로파일 XML은 여러 파일을 선택해 기존 목록에 합칠 수 있다. 동일한 교정값은 중복 제거하며 서로 다른 값은 목록에 유지한다. 제조사·렌즈 이름·초점거리 등의 단어를 검색하고, 같은 이름의 교정값은 교정 그룹·크롭 배율·비율·항목 번호로 구분한다. 카메라 촬영 정보로 찾기는 호환되는 가장 가까운 크롭 교정을 선택하며 같은 조건에서 충돌하면 직접 선택하도록 안내한다. 불러온 목록을 비워도 현재 사진에 선택한 교정값은 유지한다.

불러온 렌즈 XML 경로는 데이터 폴더의 `lens-library.json`에 저장하고 다음 실행 때 별도 작업에서 복원한다. 불러오는 동안 편집할 수 있고 취소하거나 목록을 다시 불러올 수 있다. 파일 누락/손상과 설정 저장 실패는 표시하며 기존 목록/설정 파일을 유지한다. 목록 비우기는 저장한 경로도 비우며 사진에 적용한 교정값은 유지한다. 손상된 설정은 자동 덮어쓰지 않으며 그 실행에서 새로 불러온 목록은 실행 중에 유지한다. XML 데이터베이스를 실행 프로그램에 기본 포함하지 않는다.

RAW에 렌즈 교정값을 선택하면 촬영 회전·뒤집기 방향을 연결한다. 보정 중심과 접선 모델은 촬영 원래 축에서 계산하며 표시 픽셀을 다시 회전시키지 않는다. 렌즈 프로파일의 방향 선택으로 교정 좌표 방향을 바꿀 수 있다. 이전 프로젝트에 방향 값이 없으면 기본 방향으로 유지하며 필요하면 촬영 정보로 다시 선택한다. 8가지 EXIF 방향의 합성 검사이며 실제 카메라/Fuji 특수 센서/전체 색 관리 검증은 남아 있다.

기본 색 보정과 곡선·선택 영역 혼합은 넓은 정밀도의 중간 계산을 사용하고 32비트 float 표현 범위 밖 값만 제한한다. 음수/HDR RGB와 작은 알파를 유지하며 효과가 없을 때는 픽셀 비트를 유지한다. 전체 합성/공간 필터·ICC 변환·HDR 화면의 검증 완료와 구분한다.

이미지 변형의 공통 양선형·쌍입방 보간은 선곱 RGB/알파를 넓은 정밀도에서 누산하고 아주 작은 양수 알파도 유지한다. 최근접은 원래 픽셀 비트를 유지한다. 렌즈 교정 전용 경로와 공통 경로를 같은 정밀도로 연결했다. 전체 블렌드 모드/공간 필터/색 관리의 극값 검증은 남는다.

Normal 합성과 통과 그룹의 불투명도·마스크 혼합은 넓은 정밀도에서 선곱 RGB/알파를 누산하며, 음수/HDR와 작은 알파를 유지한다. Dissolve의 위치/시드에 따른 분포도 유지한다. 다른 블렌드 모드와 공간 필터의 극값·ICC/HDR 화면 검증은 남는다.

가우시안 흐림은 일반 사진의 기존 최적화 경로를 유지하며, 큰 HDR 값·음수·작은 알파와 극소 반경에는 f64 중간 계산을 사용한다. 확산·프로젝트·출력에서도 유한한 32비트 저장 범위를 유지한다. 색 공간과 대형 문서 성능 검증은 별도 남은 작업이다.

모션 흐림과 기본 선명화도 f64 중간 계산으로 큰 HDR 값·음수와 작은 알파를 처리한다. 기존 모션 샘플 위치/외곽 정책과 선명화 강도는 유지하며 결과만 유한 f32 저장 범위로 제한한다.

사진 블룸의 밝기 추출·광량 합산·알파 확산도 f64 중간 계산을 사용한다. 알파 유지와 경계 밖 확산 모두 HDR 극값/작은 알파에서 유한한 결과를 저장하며, 무효 설정은 원본을 유지한다.

톤별 대비는 밝기·그림자/중간톤/하이라이트 가중치와 양수/음수 세부 차이를 f64에서 계산한다. 큰 HDR 값에서도 유한 f32 결과를 저장하고 원래 알파/숨은 RGB·선택 영역·프로젝트 설정을 유지한다.

27개 블렌드 모드의 float 작업 합성은 f64 중간 계산을 사용한다. 스크린·소프트 라이트의 흰색 경계, 제외·선형 모드의 중립값과 색조 계열의 광도 상쇄를 보강했다. 모드 자체의 기존 밝기/색 제한은 유지하며, 레이어 혼합 후 유한 f32 결과를 저장한다. 극값 상쇄의 수치 허용오차는 검증 기록을 따른다.

RAW 현상의 “화이트 밸런스 스포이드”를 켜고 현상 결과에서 흰색·회색 부분을 클릭하면 주변 평균으로 사용자 화이트 밸런스를 맞춘다. 샘플 반경은0–64px이며 노출은 유지한다. 화면에 표시한 색 대신 검정값 정규화/디모자이크/자르기 후의 WB·노출 전 카메라 채널을 사용한다. 최신 선택만 적용하고 설정/반경 변경·스포이드 해제·취소는 이전 계산을 무효화한다. 계산 실패는 원본을 유지하고 미리보기 실패는 “미리보기 다시 계산”으로 재시도한다.

스포이드는 실제 센서 현상 결과를 새로 준비한 뒤 사용할 수 있다. 기존 사진을 직접 그리거나 크기를 바꾼 경우에도 비교용 원본은 유지한다. 재현상으로 레이어 크기가 달라지면 기존 마스크 픽셀/화면 위치·연결 상태를 보존하고 저장 가능한 배치로 기록한다. 원근 변형이나 설정을 유지할 수 없으면 적용을 거부하고 기존 레이어를 유지한다. 3채널 촬영값/기본 배율의 .rphoto v9 설정은 유지하며 색온도·틴트는 v10, 4채널 정보/배율은 v11로 기록한다. 다중 광원·실제 카메라/4색 CFA 전수·ICC/RAW 옆 패널은 남은 목표다.

가져온 SVG의 로컬 이미지 참조는 원래 SVG 폴더와 `xml:base`를 기준으로 읽어 문서 안에 포함한다. PNG/JPEG/GIF/WebP 등 지원 형식은 원본 바이트를 보관하며, 방향·첫 화면·고비트 표시나 렌더러가 직접 읽지 못하는 형식은 PNG 미리보기도 함께 보관해 원본 이미지 이동 후에도 프로젝트/SVG 출력을 복원한다. 누락·순환·손상·보관 예산 초과는 오류로 알리며 원격 이미지·외부 글꼴/CSS·고정밀 SVG 표시와 애니메이션은 남은 목표다. 현재 보관 예산은 총 원본/내장 소스 64MiB이며 형식의 지원 크기 상한과 구분한다.

SVGZ는 압축 SVG로 열기·중첩 이미지·내보내기 형식 선택과 출력 미리보기에서 지원한다. SVG 사진의 EXIF 방향, GIF의 논리 화면/프레임 위치, APNG 기본 이미지와 WebP 첫 화면은 일반 이미지 열기와 맞춘다. 원래 이미지의 방향/ICC/프레임/고비트 바이트 보관과 실제 애니메이션·색 관리·고정밀 SVG 표시는 구분한다. 현재 출력 형식 선택은 SVGZ·JP2·J2K를 포함해19개다.

SVG 레이어의 **요소 편집**에서 image/feImage를 선택하면 **찾아보기** 또는 파일 경로로 이미지를 교체할 수 있다. 위치·크기·변형·스타일과 다른 요소를 유지하고, 문서에 이미지/원본을 포함한 미리보기를 확인한 다음 최종 적용한다. 가져오기 취소·편집 창 취소는 문서 이력을 만들지 않으며 적용은 한 번 실행 취소할 수 있다. 큰 내장 데이터는 목록에서 직접 복사하지 않고 원본 XML은 펼쳐 편집한다.

SVG 요소 편집에서 **원본 파일 저장**은 보관한 처음 파일의 바이트를 그대로 꺼낸다. RAW·TIFF·HDR 정밀도와 원래 메타데이터/프레임을 유지한다. **표시용 이미지 저장**은 SVG에서 사용하는 방향/첫 화면/표시 형식을 반영한 파일을 꺼낸다. 원본 SVG의 파일 참조는 원래 소스에 남을 수 있으므로 로컬 이미지가 포함된 SVG가 필요하면 표시용 파일을 저장한다. 레이어의 위치·마스크·효과까지 반영한 결과는 이미지 내보내기에서 저장한다. 이 두 파일 저장은 문서 이력을 바꾸지 않는다.

RAW 현상에서 “색온도·틴트”를 선택하면 Kelvin1000–50000과 틴트−200–200을 조절한다. 색온도는 CIE 관측자/Planck 광원과 카메라 색 행렬로 센서 배율을 계산한다. 틴트는 −초록/+자홍이며 이 앱의 UCS 법선 이동 단위이므로 다른 편집기의 동일 숫자와 같다고 표시하지 않는다. 촬영값·사용자 배율·EV·흰색/회색 스포이드도 유지한다. 광원이나 카메라 행렬에서 양의 배율을 계산할 수 없으면 오류를 표시하고 적용하지 않는다. 흑백 센서는 색온도·틴트의 색 변화가 없다. 데이터 출처/CC BY-SA 4.0 고지는 [CIE 데이터 안내](data/cie/README.md)에 있다.

렌즈 프로파일의 “XML 파일 변경 자동 반영”은 등록 파일의 내용을5초 간격으로 백그라운드 확인한다. 변경되면 전체 목록을 새로 읽으며 삭제된 교정 기록도 목록에서 제거한다. 삭제/손상/읽기 예산 초과나 읽는 중 변경은 기존 목록을 유지하고 오류를 표시한다. 파일이 정상 내용으로 바뀌면 다시 불러온다. 끄기/켜기는 재실행 후에도 유지한다. 현재 사진에 선택한 교정값과 원본 XML은 목록 갱신에 따라 자동으로 바뀌지 않는다. 이 기능은 편집기 실행 중의 파일 감지이며 Codex 예약 작업을 켜지 않는다.

RAW 현상의 센서→WB/색 행렬→선형 EV→sRGB 곡선 계산은64비트 중간값을 사용한다. 유한32비트 최대 센서에 큰 배율/노출을 적용해도 중간값이 먼저 넘치지 않으며 최종32비트 저장 범위를 넘는 결과만 제한한다. 카메라 광원/행렬의 정규화·부분 피벗 역변환도64비트로 계산한다. 센서 정규화/디모자이크 전체의 고정밀화·실제 카메라/색 관리 검증은 남는다.

4채널 RAW는 네 번째 센서 채널을 투명도로 취급하지 않고 카메라 색 행렬에 포함한다. 사용자 지정에서 네 번째 배율을 조절하며 실제 CFA 색 목록이 있으면 청록·자홍·노랑 등 채널 이름을 표시한다. 목록이 없으면 순서로 표시한다. 촬영값은4개 AsShotNeutral을 사용하고 중립은4개 배율1을 사용한다. 스포이드는 네 번째 채널을 포함한 모든 센서 배율을 함께 계산하고 사용자 지정 배율로 기록한다. 비D65 단일 광원/3×3·4×3 행렬과 자체 RGB/Cyan·CMYG·순서 변경4색 CFA 내부를 검사했다. Daylight/Flash 광원은 현재 D65/D55 근사이며 실제 센서/경계·전체 CFA·다중 광원/ForwardMatrix/AnalogBalance/ICC는 남은 목표다. 이전4채널 DNG 프로젝트의 유효한 센서 정보는 보관 원본에서 복원하며 기존 저장 픽셀을 바꾸지 않고 다음 저장에 v11을 사용한다.

순차83: RAW 색온도 모드는 두 광원의 행렬을 역색온도에 따라 보간하고 선택한 Kelvin/틴트 광원으로 색을 변환한다. 범위 밖은 가까운 프로파일을 사용한다. 단일 프로파일에도 선택한 광원 변환을 적용한다. 기존 .rphoto 저장 픽셀은 그대로 열고 재현상 시 새 계산을 적용한다. 촬영/사용자 지정 모드의 이중 광원, 3광원/전체 DNG 프로파일·실제 센서/ICC 검증은 남는다.

순차84: 촬영값 모드도 두 광원의 카메라 행렬을 촬영 화이트밸런스에 맞춰 선택하고 색을 변환한다. 광원 색상을 반복 계산하며 계산 불가/수렴 실패를 오류로 알린다. 단일 광원의 기존 계산은 유지한다.

순차85: 사용자 지정 배율도 이중 광원 색 변환에 반영한다. 흰색/회색 스포이드는4채널이면 네 번째 배율까지 함께 계산하고3채널이면 기존 설정 필드 정책을 유지한다. 센서 기준 채널의 배율은1이며 EV·비활성 Kelvin/틴트는 유지한다. 유효한 광원/현재 배율 범위를 계산할 수 없으면 현재 설정을 유지하고 오류를 알린다. 선택한 부분의 중립색, 미리보기/취소/적용/프로젝트와PSD·PSB·EXR 출력은 자동 검사했다. 전체DNG 프로파일/3광원·CC/AB/Forward/Reduction/DNG 룩·실제 센서/ICC는 남는다.
